# Non-Standard Code to Production-Ready Package

This project aims to refactor non-standard code into a modular, reusable, and testable production-ready package with proper testing, logging, and continuous integration workflows using GitHub Actions. It involves organizing the code, creating reusable modules, setting up testing environments, logging functionality, and automating the development workflow.

## Project Structure

The project follows a clean and modular structure. Here's an overview of the main directories and files:

- **src/**: Contains the core logic of the package.
- **scripts/**: Contains Python scripts for various tasks such as data ingestion, training, and scoring.
- **tests/**: Contains unit tests for verifying the correctness of the package functionality.
- **.github/**: Contains GitHub Actions workflows for CI/CD.
- **setup.py**: Packaging script for installing the package.
- **requirements.txt**: Lists required dependencies for the project.
- **env.yml**: Conda environment setup file.
